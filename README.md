## 🚀 Professional Work

### ADAS Fleet Operations & Analytics Platform
*A suite of internal web applications deployed on AWS EC2*
`Python` `React` `Node.js` `MongoDB` `DynamoDB` `S3` `AWS IoT Core (MQTT)` `Socket.IO`

| Project | What it does | Impact |
|---|---|---|
| **Trip Reporting** | Automated trip reports for 1000+ devices using parallel reads across five DynamoDB tables and a scheduled MongoDB cache, with live updates over Server-Sent Events | Saves ~5 hours/day |
| **ROI Calibration Tool** | Web tool for reviewing incident videos (S3, DynamoDB) and setting ROI regions for FCW and DSM devices | No developer involvement needed |
| **OTA Firmware Automation** | State-machine-based upgrade workflow for dashcam devices over MQTT, with job state in MongoDB and a tracking dashboard | Replaced manual tracking |
| **Device Command Center** | Real-time command dispatch through IoT Core with response tracking over Socket.IO | Live device control |
| **Self-Service Dashboard** | Replaced manual database queries with a self-service interface | 70% faster data lookup |
| **Record-Keeping Automation** | Automated a manager's manual record-keeping process | ~2 hours saved/day |

> These are internal company tools, so source code is private. Happy to walk through the architecture in an interview.
